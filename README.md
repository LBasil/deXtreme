# DeXtreme

Jeu de dés contre une IA, en JavaScript vanilla (HTML, CSS, Bootstrap), sans build.

Les deux camps ont 100 points de vie. À chaque tour, tu mises, tu lances le dé, et les dégâts dépendent du résultat, des combos et des victoires consécutives. Un combat de boss se déclenche en cours de partie, et un écran de fin résume la partie.

## Lancer

Ouvrir `index.html` dans un navigateur.

## Fichiers

- `index.html` : interface
- `script.js` : règles, IA, combos, boss, écran de fin
- `styles.css` : styles

Démo : https://de-xtreme.vercel.app/
